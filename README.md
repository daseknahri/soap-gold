# Soap Gold — "The soaps you grew up with — their greatest stories, told properly."

UK soaps **heritage** fan site for **Emmerdale** and **Coronation Street**: classic
storylines retold, on-this-day anniversaries, iconic characters, milestones, and the
sets/locations fans visit. Written for the owner's Facebook groups (~52K members).
Served (in the next phase) at **soapgold.getemoji.site**. WordPress on Docker (Coolify),
fully set up on first start — no wp-admin clicks needed. Cloned from the dales-cobbles
repo (the germ/roman self-seeding pattern, Style A of the plgin new-site playbook) and
rebranded: same self-seeding engine, heritage pillars instead of spoiler/news pillars.

## What's inside
- `wp-content/themes/viral-reader` — parent theme (vendored, v1.9.37, from plgin `main`)
- `wp-content/themes/soap-gold` — brand child theme (v1.0.0): self-hosted Literata serif
  (display + body), BRAND.md tokens (parchment cream #F7F0DC, deep burgundy #6E1423,
  antique gold #C9A227, ink #2B2118), category-coloured pillars, end-of-article share +
  "next article" flow, sticky next-article bar, dark mode
- `wp-content/plugins/automation-hamri` — publishing/SEO/ads engine (vendored, build-v9
  9.48.0 from plgin `main` — the released version; 9.48.1 exists only on the unmerged
  BL-010 branch and was deliberately NOT vendored)
- `wp-content/mu-plugins/sg-page-cache.php` — tiny full-page cache (per URL +
  phone/desktop key, 30 min TTL, purge on publish; logged-in/commenters bypass).
  Header `X-SG-Cache: hit` on hits.
- `content/site-profile.json` — brand identity (name/tagline/email, writer, assets,
  locales, slugs, categories). The seed reads it for brand/categories; `seed/seed.php`
  holds the fallbacks.
- `content/images/` — committed raster brand assets (icon, logos, OG card, hero).
  Never hotlinked.
- `data/bundles/*.zip` — article bundles (posts.json + images) imported on first start;
  empty at launch until the first content batch lands.
- `seed/seed.php` — brand, en_GB locale, 5 heritage categories, 7 trust pages, menus,
  stage-1 ads.txt, bundle import (idempotent, resumable). `SG_SEED_VERSION` 1.
- `docker/site-init.sh` — waits for DB, syncs theme/plugin, installs WP (en_GB) once,
  runs the seed.

## Heritage pillars (seeded categories)
Classic Storylines Retold · On This Day · Iconic Characters · Anniversaries &
Milestones · Sets, Locations & Tours (`vr_noun=article`; publishing note: publish by
numeric category ID — names with `&` duplicate on name matching.)

## Coolify (next phase — owner approvals)
Docker Compose build pack, compose file `docker-compose.yml` ONLY, domain on the
`wordpress` service. Env vars:
- `SERVICE_FQDN_WORDPRESS_80` (the domain), `SERVICE_USER_MYSQL`,
  `SERVICE_PASSWORD_MYSQL`, `SERVICE_PASSWORD_MYSQLROOT`, `SERVICE_PASSWORD_WPADMIN`
  — generated by Coolify
- `SITE_URL` (default https://soapgold.getemoji.site), `SITE_EMAIL`, `WP_ADMIN_EMAIL`
- `ADSENSE_CLIENT` / `ADSENSE_PUB_ID` — default ca-pub-6869205417923902 /
  pub-6869205417923902 (getemoji.site family publisher); `ADSENSE_ENABLE=0` at launch
  (stage 1: ads.txt served, no ads — the domain is already approved at family level)
- `GA_ENABLE=0`, `HISTATS_ID` unset/off — analytics off until the owner creates the
  properties
- Google Site Kit — installed/activated by site-init.sh from wordpress.org; owner
  connects Analytics/AdSense in wp-admin. The theme blocks Site Kit's duplicate
  AdSense snippet.

Admin login: user `editor` (WP_ADMIN_USER), password = Coolify's
`SERVICE_PASSWORD_WPADMIN`.

## Local QA
```
copy .env.example .env   (fill in fresh random passwords + salts — never a sibling's .env)
docker compose -f docker-compose.yml -f docker-compose.local.yml up -d --build
# http://localhost:8099 — WP_ENVIRONMENT_TYPE=local applies only in this override
docker compose -f docker-compose.yml -f docker-compose.local.yml down   (volumes kept)
```

## Editorial rules (from BRAND.md)
Warm, knowledgeable, fan-to-fan heritage writing. Every feature checked against the
original broadcasts, listings and contemporary interviews; memories and theories
labelled as such; never fabricate storylines, quotes or dates. No ITV stills, cast
photos or show logos anywhere on the site; brand art is original. Soap Gold is an
unofficial fan publication, not affiliated with ITV.
